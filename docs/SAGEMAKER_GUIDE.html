0. What this guide is

Validated Every command and file in this guide was run end to end in AWS account 240939827174, region ap-south-1, on 2026-11-02. Code, dataset validation, training, evaluation and music generation all ran in AWS (CodeBuild + SageMaker). The laptop only edited files, uploaded the source zip, and sent AWS CLI calls. Section 16 is the run log with measured numbers. Section 15 lists the 17 problems the run found and how each is fixed in the files below.

1. The better solution

What changed compared with the laptop project, and what the validation run measured for each change.

#Laptop projectSageMaker projectMeasured in the run
B1Train at 1 024 tokens, generate 2 560 (unseen positions)Train at 2 560 tokensfits in 9.0–9.8 GB of the A10G's 24 GB (batch 8)
B2fp32 on MPS (the amp key was ignored)bf16 autocast + TF32≈65 000 (A10G) / ≈46 000 (L4) tokens/s vs 65–174 on the M2
B3JSONL of Python lists, all in RAMuint16 memmap shards + JSONL index20 000 pieces = 463 MB on disk
B4Each piece truncated to its first N tokensFull pieces, random bar-aligned 2 560-token window per step87 % of pieces are longer than 2 560 tokens, so most data was being thrown away
B5Logged train loss divided by the epoch's batch count (bug)Divide by examples since the last logtrain and validation loss now agree (e.g. 1.80 / 1.73 at step 1 000)
B6Full mT5 from the Hub at run time (4.3 GB cache)Encoder-only mT5 exported once to S3 (1.0 GB, safetensors)no Hub download in training or serving
B7Resume restarts the epochAuto-resume from /opt/ml/checkpoints, skip seen batchesstopped at step 1 150, new job on a different GPU (L4) resumed at step 1 000: 0 missing tensors, loss 1.80 → 1.79, LR schedule continued
B8generate() reloads the checkpoint per callLoad once per containermodel load 6.9 s once; a song takes 18 s (instrumental) to 61 s (sung) of compute
B9CLI on a laptopAsync endpoint, autoscaling 0 ↔ 1scale-to-zero validated (0 instances while idle)
B10Manual evaluateEvaluate at the end of training on the same GPUevaluation.json in S3 + in the model registry

B12Tests run on the laptopTests run inside the image build (CodeBuild)caught a real Linux-only bug (V5)

Considered and rejected

  • Pre-computing mT5 embeddings. About 25 GB of features for the full corpus. The frozen encoder forward is cheap next to the decoder backward at 2 560 tokens.
  • Real-time / serverless endpoints. Real-time has a 60 s limit; serverless has no GPU.
  • Managed spot for this account and region today. The guide keeps the spot template (it is ~3× cheaper), but in the run neither g5 nor g6 spot got capacity in 30 minutes. Plan for on-demand fallback (V10).

"""Token shards written by ``sagemaker/entry/prepare.py``.

``tokens_<rank>.bin``   every piece of one shard, concatenated, ``uint16``
``index_<rank>.jsonl``  ``{"offset", "length", "text", "location", "split"}`` per piece

The music vocabulary has 423 tokens, so two bytes per token is enough: the
full MidiCaps corpus fits in about 1 GB instead of many GB of Python ints.
"""
from __future__ import annotations

import json
import random
from pathlib import Path
from typing import Any

import numpy as np
import torch
from torch.utils.data import Dataset


class TokenShardDataset(Dataset):
    """Memory-mapped token shards with random, bar-aligned training windows."""

    def __init__(
        self,
        root: str | Path,
        split: str,
        window: int,
        bar_id: int | None = None,
        random_crop: bool = True,
    ):
        self.root = Path(root)
        self.window = int(window)          # music tokens per example, BOS/EOS excluded
        self.bar_id = bar_id
        self.random_crop = random_crop and split == "train"
        self.items: list[tuple[str, int, int, str]] = []
        for index in sorted(self.root.glob("index_*.jsonl")):
            rank = index.stem.split("_", 1)[1]
            with index.open(encoding="utf-8") as fh:
                for line in fh:
                    r = json.loads(line)
                    if r["split"] == split:
                        self.items.append((rank, int(r["offset"]), int(r["length"]), r["text"]))
        self._maps: dict[str, np.memmap] = {}   # opened lazily, once per DataLoader worker

    def _map(self, rank: str) -> np.memmap:
        if rank not in self._maps:
            self._maps[rank] = np.memmap(self.root / f"tokens_{rank}.bin", dtype=np.uint16, mode="r")
        return self._maps[rank]

    def __len__(self) -> int:
        return len(self.items)

    def window_start(self, piece: np.ndarray, rng: random.Random | None = None) -> int:
        """Random start, snapped back to the closest bar line at or before it."""
        n = len(piece)
        if not self.random_crop or n <= self.window:
            return 0
        start = (rng or random).randint(0, n - self.window)
        if self.bar_id is not None:
            bars = np.flatnonzero(piece[: start + 1] == self.bar_id)
            start = int(bars[-1]) if bars.size else 0
        return start

    def __getitem__(self, i: int) -> dict[str, Any]:
        rank, off, n, text = self.items[i]
        piece = self._map(rank)[off: off + n]
        start = self.window_start(piece)
        ids = np.asarray(piece[start: start + self.window], dtype=np.int64)
        return {"ids": torch.from_numpy(ids), "text": text, "index": i}

def validate(report: dict, thresholds: argparse.Namespace) -> list[str]:
    """Return the list of failed checks (empty = dataset is usable)."""

    if report["kept_ratio"] < thresholds.min_kept_ratio:
        failed.append(f"kept ratio {report['kept_ratio']:.3f} < {thresholds.min_kept_ratio}")
    if report["max_token_id"] >= report["vocab_size"]:

    if report["split"].get("val", 0) == 0:

        failed.append(f"{report['empty_text']} pieces without caption text")
    if report["duplicate_locations"] > 0:
        failed.append(f"{report['duplicate_locations']} duplicate MIDI locations")
    return failed

sagemaker/entry/train_sm.py
"""SageMaker Training entry: dataset gate -> promptmusic.train -> package -> evaluate.

Container paths (fixed by SageMaker):
    /opt/ml/input/config/hyperparameters.json   string -> string overrides
    /opt/ml/input/data/train/                   token shards + validation_*.json
    /opt/ml/input/data/encoder/                 encoder-only mT5
    /opt/ml/checkpoints/                        synced to S3 (spot resume)
    /opt/ml/model/                              -> model.tar.gz
    /opt/ml/output/data/                        -> output.tar.gz (samples, reports)
    /opt/ml/output/failure                      -> DescribeTrainingJob.FailureReason
"""
from __future__ import annotations

import json
import logging
import os
import shutil
import sys
import traceback
from pathlib import Path

logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s",
                    stream=sys.stdout)
LOG = logging.getLogger("train_sm")

PREFIX = Path("/opt/ml")
HP_FILE = PREFIX / "input/config/hyperparameters.json"
CH_TRAIN = PREFIX / "input/data/train"
CH_ENCODER = PREFIX / "input/data/encoder"
CKPT = PREFIX / "checkpoints"
MODEL = PREFIX / "model"
OUT_DATA = PREFIX / "output/data"
FAILURE = PREFIX / "output/failure"
RUN = "prompt_music_gen"
VOICE = "facebook/mms-tts-tam"

EVAL_PROMPTS = [
    "a romantic tamil love song, gentle and emotional",
    "an upbeat pop song with drums, bass and electric guitar",
    "a calm piano ballad in a minor key",
    "a fast electronic dance track with synth lead",
]


def hyperparameters() -> dict[str, str]:
    return json.loads(HP_FILE.read_text()) if HP_FILE.exists() else {}


def dataset_gate() -> dict:
    """Refuse to train on shards whose validation report failed."""
    reports = [json.loads(p.read_text()) for p in sorted(CH_TRAIN.glob("validation_*.json"))]
    if not reports:
        raise RuntimeError(f"no validation_*.json in {CH_TRAIN}; run the prepare job first")
    bad = [r for r in reports if not r.get("valid")]
    if bad:
        raise RuntimeError(f"dataset validation failed: {[r['checks_failed'] for r in bad]}")
    summary = {
        "pieces": sum(r["kept"] for r in reports),
        "tokens": sum(r["tokens_total"] for r in reports),
        "train": sum(r["split"].get("train", 0) for r in reports),
        "val": sum(r["split"].get("val", 0) for r in reports),
    }
    LOG.info("dataset gate passed: %s", summary)
    return summary


def main() -> None:
    import torch

    LOG.info("torch %s, cuda %s, gpu %s", torch.__version__, torch.version.cuda,
             torch.cuda.get_device_name(0) if torch.cuda.is_available() else None)
    hp = hyperparameters()
    config = hp.pop("config", "sagemaker")
    num_eval = int(hp.pop("eval_samples", len(EVAL_PROMPTS)))
    data_summary = dataset_gate()

    os.environ["PROMPTMUSIC_TEXT_ENCODER"] = str(CH_ENCODER)
    overrides = [f"paths.output_dir={CKPT}", f"data.token_dir={CH_TRAIN}", "train.device=cuda"]
    overrides += [f"{k}={v}" for k, v in hp.items()]

    last = CKPT / RUN / "checkpoints" / "last.pt"
    if last.exists():
        LOG.info("resuming from %s (spot restart or re-run)", last)
        overrides.append(f"train.resume={last}")
    LOG.info("overrides: %s", overrides)

    from promptmusic.train import train
    summary = train(config, overrides=overrides)
    LOG.info("train summary: %s", json.dumps(summary, default=str))
    if torch.cuda.is_available():
        LOG.info("peak GPU memory: %.2f GB", torch.cuda.max_memory_allocated() / 1e9)

    best = CKPT / RUN / "checkpoints" / "best.pt"
    package(best if best.exists() else last)
    metrics = evaluate(MODEL / "model.pt", num_eval)
    metrics["dataset"] = data_summary
    metrics["train"] = {k: v for k, v in summary.items() if k != "history"}
    text = json.dumps(metrics, indent=2, default=str)
    (MODEL / "evaluation.json").write_text(text)
    (OUT_DATA / "evaluation.json").write_text(text)
    upload_eval(MODEL / "evaluation.json")


def package(ckpt: Path) -> None:
    """model.pt (no optimizer/scheduler) + encoder + Tamil voice = self-contained model dir."""
    import torch
    from huggingface_hub import snapshot_download

    payload = torch.load(ckpt, map_location="cpu", weights_only=False)
    for key in [k for k in payload if k.startswith(("optimizer", "scheduler"))]:
        payload.pop(key)
    MODEL.mkdir(parents=True, exist_ok=True)
    torch.save(payload, MODEL / "model.pt")
    shutil.copytree(CH_ENCODER, MODEL / "encoder", dirs_exist_ok=True)
    snapshot_download(VOICE, local_dir=MODEL / "voice",
                      allow_patterns=["*.json", "*.safetensors", "*.txt", "*.model"])
    LOG.info("packaged %s from %s (%.0f MB)", MODEL / "model.pt", ckpt.name,
             (MODEL / "model.pt").stat().st_size / 1e6)


def evaluate(model_pt: Path, n: int) -> dict:
    from promptmusic.evaluate import evaluate_files
    from promptmusic.generate import generate

    out = OUT_DATA / "samples"
    out.mkdir(parents=True, exist_ok=True)
    mids = []
    for i, prompt in enumerate(EVAL_PROMPTS[:n]):
        res = generate(prompt, checkpoint=model_pt, out_dir=out, max_new_tokens=1600,
                       render_audio=False, seed=1000 + i, device="cuda")
        mids += [r.midi_path for r in res if r.midi_path]
    result = evaluate_files(mids, keep_per_file=True)
    metrics = result.to_dict()
    LOG.info("evaluation: %s", json.dumps(metrics, default=str)[:3000])
    return metrics


def upload_eval(path: Path) -> None:
    uri = os.environ.get("EVAL_S3_URI")
    if not uri:
        return
    import boto3
    bucket, key = uri.removeprefix("s3://").split("/", 1)
    boto3.client("s3").upload_file(str(path), bucket, key)
    LOG.info("uploaded %s", uri)


if __name__ == "__main__":
    try:
        OUT_DATA.mkdir(parents=True, exist_ok=True)
        main()
    except Exception:
        FAILURE.parent.mkdir(parents=True, exist_ok=True)
        FAILURE.write_text(traceback.format_exc()[-1000:])
        LOG.exception("training job failed")
        sys.exit(1)

sagemaker/entry/serve.py
"""SageMaker async endpoint: prompt (+ lyrics) -> zip of raw MIDI, arranged MIDI, WAV, meta.

Contract: listen on 8080, GET /ping -> 200 when ready, POST /invocations.
The model is loaded once per container (generate() would otherwise reload
the 1.3 GB checkpoint on every request).
"""
from __future__ import annotations

import functools
import io
import json
import logging
import os
import sys
import tempfile
import time
import zipfile
from pathlib import Path

import torch
from flask import Flask, Response, request

logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s",
                    stream=sys.stdout)
LOG = logging.getLogger("serve")

MODEL_DIR = Path(os.environ.get("SM_MODEL_DIR", "/opt/ml/model"))
MODEL_PT = str(MODEL_DIR / "model.pt")
VOICE = str(MODEL_DIR / "voice") if (MODEL_DIR / "voice").is_dir() else "facebook/mms-tts-tam"
os.environ.setdefault("PROMPTMUSIC_TEXT_ENCODER", str(MODEL_DIR / "encoder"))
DEVICE = "cuda" if torch.cuda.is_available() else "cpu"
TOKENS_PER_SECOND = 40          # measured MidiCaps density
MAX_SECONDS = 64                # 2560 training tokens / 40
LYRICS_DIR = Path("/opt/program/data/lyrics")

import promptmusic.generate as G  # noqa: E402
from promptmusic.arrange import arrange_midi  # noqa: E402
from promptmusic.render import render_midi  # noqa: E402
from promptmusic.singing import sing_song  # noqa: E402

G._load_for_inference = functools.lru_cache(maxsize=1)(G._load_for_inference)
_t = time.time()
G._load_for_inference(MODEL_PT, None, DEVICE)
LOG.info("model loaded on %s in %.1fs (voice: %s)", DEVICE, time.time() - _t, VOICE)

app = Flask(__name__)


@app.get("/ping")
def ping():
    return Response("ok", status=200)


@app.post("/invocations")
def invocations():
    req = json.loads(request.get_data().decode("utf-8"))
    prompt = req["prompt"]
    lyrics = req.get("lyrics", "")
    if not lyrics and req.get("lyrics_file"):           # a file baked into the image
        name = Path(req["lyrics_file"]).name              # no path traversal
        lyrics = (LYRICS_DIR / name).read_text(encoding="utf-8")
    language = req.get("language", "en")
    duration = min(float(req.get("duration", 45)), MAX_SECONDS)
    sing = bool(req.get("sing", bool(lyrics)))
    t0 = time.time()
    LOG.info("request: %s", json.dumps({k: v for k, v in req.items() if k != "lyrics"}, ensure_ascii=False))

    with tempfile.TemporaryDirectory() as td:
        td = Path(td)
        res = G.generate(
            prompt, checkpoint=MODEL_PT, out_dir=td, render_audio=False,
            max_new_tokens=int(duration * TOKENS_PER_SECOND), lyrics=lyrics, language=language,
            seed=req.get("seed"), device=DEVICE,
            temperature=float(req.get("temperature", 0.95)), top_p=float(req.get("top_p", 0.92)),
        )[0]
        arranged, report = arrange_midi(res.midi_path, td / "arranged.mid")
        wav = td / "song.wav"
        sung = None
        if sing and lyrics:
            sung = sing_song(arranged, lyrics=lyrics, out_path=wav, voice=VOICE, device="cpu")
        else:
            render_midi(arranged, wav)

        meta = {
            "prompt": prompt, "language": language, "requested_seconds": duration,
            "num_tokens": res.num_tokens, "num_notes": res.num_notes,
            "midi_seconds": res.duration_sec, "sung": bool(sung),
            "sing": sung.to_dict() if sung is not None else None,
            "arrangement": report.to_dict() if hasattr(report, "to_dict") else str(report),
            "compute_seconds": round(time.time() - t0, 1), "device": DEVICE,
        }
        buf = io.BytesIO()
        with zipfile.ZipFile(buf, "w", zipfile.ZIP_DEFLATED) as z:
            z.write(res.midi_path, "raw.mid")
            z.write(arranged, "arranged.mid")
            z.write(wav, "song.wav")
            z.writestr("meta.json", json.dumps(meta, ensure_ascii=False, indent=2, default=str))
    LOG.info("done in %.1fs", time.time() - t0)
    return Response(buf.getvalue(), status=200, mimetype="application/zip")

infra/deploy.sh
#!/usr/bin/env bash
# infra/deploy.sh <model-package-arn>  -- create or update the async endpoint
#
# Tries each instance type in INSTANCE_TYPES in order until one gets capacity.
# Run infra/autoscale.sh afterwards: autoscaling must be removed before an
# update that changes the instance type, so this script removes it.
set -euo pipefail
source "$(dirname "$0")/env.sh"
PKG=$1; EP=${EP:-${PROJECT}-async}
INSTANCE_TYPES=${INSTANCE_TYPES:-"ml.g5.xlarge ml.g6.xlarge ml.c6i.2xlarge"}   # GPU first, CPU last
RID=endpoint/$EP/variant/AllTraffic; DIM=sagemaker:variant:DesiredInstanceCount

EXISTS=0; aws sagemaker describe-endpoint --endpoint-name $EP >/dev/null 2>&1 && EXISTS=1
if [ $EXISTS = 1 ]; then
  # "The variant(s) must be deregistered as scalable targets ... before they can
  #  ... have their instance type updated"
  aws application-autoscaling deregister-scalable-target --service-namespace sagemaker \
    --resource-id $RID --scalable-dimension $DIM 2>/dev/null && echo "autoscaling removed (re-run infra/autoscale.sh)" || true
  aws cloudwatch delete-alarms --alarm-names $EP-has-backlog
fi

for IT in $INSTANCE_TYPES; do
  NAME=pm-$(date +%Y%m%d-%H%M%S)
  aws sagemaker create-model --model-name $NAME --execution-role-arn $ROLE_ARN \
    --primary-container ModelPackageName=$PKG >/dev/null
  # InferenceAmiVersion: the default GPU hosting AMI has driver 470 (CUDA 11.4); torch 2.6
  # needs 12.x. GPU types only - CPU instances reject a GPU AMI.
  AMI=""; case $IT in ml.g*|ml.p*) AMI="\"InferenceAmiVersion\":\"al2-ami-sagemaker-inference-gpu-3-1\",";; esac
  aws sagemaker create-endpoint-config --endpoint-config-name $NAME \
    --production-variants "[{\"VariantName\":\"AllTraffic\",\"ModelName\":\"$NAME\",
       \"InstanceType\":\"$IT\",\"InitialInstanceCount\":1, $AMI
       \"ModelDataDownloadTimeoutInSeconds\":1200,\"ContainerStartupHealthCheckTimeoutInSeconds\":1200}]" \
    --async-inference-config "{\"OutputConfig\":{\"S3OutputPath\":\"s3://$BUCKET/async/out/\",
       \"S3FailurePath\":\"s3://$BUCKET/async/fail/\"},
       \"ClientConfig\":{\"MaxConcurrentInvocationsPerInstance\":1}}" >/dev/null
  echo "trying $IT ($NAME)"
  if [ $EXISTS = 1 ]; then
    aws sagemaker update-endpoint --endpoint-name $EP --endpoint-config-name $NAME >/dev/null
  else
    aws sagemaker create-endpoint --endpoint-name $EP --endpoint-config-name $NAME >/dev/null
  fi
  sleep 30
  aws sagemaker wait endpoint-in-service --endpoint-name $EP 2>/dev/null || true
  # A failed UPDATE rolls back and is InService again on the OLD config; a failed CREATE is Failed.
  read -r STATUS LIVE < <(aws sagemaker describe-endpoint --endpoint-name $EP \
    --query "[EndpointStatus,EndpointConfigName]" --output text)
  if [ "$STATUS" = InService ] && [ "$LIVE" = "$NAME" ]; then
    echo "InService on $LIVE ($IT)"; exit 0
  fi
  echo "  failed on $IT: $(aws sagemaker describe-endpoint --endpoint-name $EP --query FailureReason --output text | cut -c1-160)"
  if [ "$STATUS" = Failed ]; then aws sagemaker delete-endpoint --endpoint-name $EP; sleep 20; EXISTS=0; fi
